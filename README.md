## Stack

Claude · Open Code · VS Code · GitHub · Supabase · Vercel · Node.js

## Uso

Abrir `index.html` en el navegador. Por defecto se sirve la webapp completa (hero, productos, estadísticas, contacto) en una sola página.

## Despliegue

- Vercel: `bibliocatalogo.vercel.app`
- Sigue los pasos usuales de `vercel deploy` o tu plataforma de hosting estática favorita.
